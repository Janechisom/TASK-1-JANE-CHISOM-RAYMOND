# Data Cleaning & Preparation Project Using Excel and Power Query

## Overview

This project focuses on cleaning and preparing a raw transactional dataset using Microsoft Excel and Power Query. The goal was to transform messy, inconsistent data into a structured, accurate and analysis-ready dataset suitable for reporting and business analysis.

Data cleaning is one of the most critical stages of the data analytics process because the quality of insights depends on the quality of the underlying data.

---

## Project Objective

The objective of this project was to:
*Improve overall data quality
*Identify and resolve common data issues
*Create a repeatable and refreshable cleaning workflow
* Prepare the dataset for future analysis, reporting and dashboard development

---

## Tools Used

* Microsoft Excel
* Power Query

---

## Data Cleaning Process

### 1. Data Profiling

Used Power Query's built-in profiling tools to assess data quality:

* Column Quality
* Column Distribution
* Column Profile

These features helped identify missing values, errors, duplicates, and inconsistencies within the dataset.

### 2. Handling Missing Values

* Identified null and blank values
* Applied appropriate cleaning techniques to improve dataset completeness

### 3. Removing Duplicates

* Detected duplicate records
* Removed duplicate entries to ensure data accuracy

### 4. Data Type Validation

Verified and corrected data types across columns, including:

* Dates
* Text fields
* Numeric values

### 5. Standardizing Data

Standardized formatting across the dataset by:

* Cleaning text fields
* Removing inconsistencies
* Ensuring uniform formatting

### 6. Data Validation

Performed validation checks to ensure:

* Data consistency

* Data integrity
* Accuracy of transformed records

### 7. Data Structuring

Reorganized the dataset into a clean and analysis-ready format suitable for downstream reporting and analytics.

## Key Outcome

A clean, reliable, and refreshable dataset was produced using Power Query's transformation workflow.

Instead of making manual spreadsheet edits, all cleaning steps were performed within Power Query, allowing the process to be easily refreshed whenever new data is added.

---

## Key Learnings

This project reinforced the importance of:

* Data quality assessment
* Data cleaning best practices
* Reproducible data transformation workflows
* Preparing datasets for business intelligence and analytics projects

The experience highlighted that effective analysis begins with clean, accurate, and trustworthy data.
